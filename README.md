# Olist E-Commerce Dashboard

## 📊 Project Overview

The Olist E-Commerce Dashboard is an interactive Power BI
dashboard developed to analyze customer behavior, payment
patterns, seller information, and delivery performance.

The project uses Olist Brazilian e-commerce data to generate
meaningful business insights through data analysis and
visualization.

## 🎯 Project Objective

The main objective of this project is to analyze e-commerce
data and understand:

- Customer behavior
- Payment methods
- Seller information
- Delivery performance
- Customer review scores
- Weekday vs weekend payment patterns

## 🛠️ Tools & Technologies

- Microsoft Excel

The dataset contains information related to Brazilian

## 📈 Dashboard Features

### 1. Payment Type & Review Score Analysis

Analyzes the number of orders by payment type for orders
with a 5-star review score.

### 2. São Paulo Customer Price & Payment Analysis

Compares average product price and average payment value
for customers from São Paulo.

### 3. Customer & Seller KPIs

Displays important business metrics such as:

- Total Customers
- Total Sellers
- 5-Star Credit Card Orders
- Pet Shop Average Delivery Time

### 4. Shipping Time vs Review Score

Analyzes the relationship between shipping time and
customer review scores.

### 5. Weekday vs Weekend Payment Analysis

Compares payment values between weekdays and weekends.

### 6. Year Slicer

Allows users to filter dashboard data by year.

## 🔍 Key Insights

- Credit Card had the highest number of orders among
  5-star reviewed orders in this analysis.
- Longer shipping times were associated with lower
  review scores.
- Weekdays accounted for a larger share of payment
  value than weekends in the current analysis.
- The dashboard provides an overview of customer,
  seller, payment, and delivery-related metrics.
